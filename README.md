# ELPrisen.nu

A responsive electricity price dashboard for Denmark, built with React, TypeScript, and Vite.

## Features

- View current and hourly electricity prices.
- Browse historical electricity prices.
- Switch between DK1 and DK2.
- Toggle VAT-inclusive pricing.
- Enable low-price notifications.
- Save settings locally.
- Responsive mobile, tablet, and desktop layouts.
- Progressive Web App support.

## Technologies

- React
- TypeScript
- Vite
- Styled Components
- React Router
- Font Awesome

## Getting Started

Clone the repository and install dependencies:

```bash
git clone https://github.com/phch42/elpriser-nu
cd <project-folder>
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```
